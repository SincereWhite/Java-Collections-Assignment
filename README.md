## About This Project

This project is a Java program I made to practice using collections. The user enters eight unique words, and the program stores them in an ArrayList and works with the list in different ways.

## What I Used

I used Java, ArrayLists, loops, user input, sorting, and conditional statements.

## Input

The user enters eight unique words through the console.

## Output

The program displays the original list, the longest and shortest words, and different sorted versions of the list. It also shuffles the list, searches for a word, and shows a few extra Collections methods.
